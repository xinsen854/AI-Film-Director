# SEVERITY MODEL

- BLOCKER: production cannot continue (missing hard source, unknown required model adapter, missing required asset/story coverage).
- ERROR: output exists but violates hard execution contract (SEEDANCE_PROMPT_STRUCTURE, SUMMARY_COLLAPSE, VOICE_MEDIA_LEAK, MODEL_WINDOW, dialogue/continuity conflict).
- WARNING: non-blocking risk or redundancy.
- INFO: metadata note only.
