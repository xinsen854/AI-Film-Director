# Director Craft Engine — Input Contract

Primary inputs:

1. `SCENE_INTELLIGENCE_RESULT`
   - scene core
   - character objectives
   - emotional mechanism
   - relationship / power dynamics
   - subtext
   - information state
   - space function
   - energy profile
   - Beat Map
   - confidence / ambiguities

2. `ROUTER_RESULT`
   - generic active capabilities
   - priority
   - HARD / SOFT / FREE metadata where relevant
   - unresolved ambiguity

## Rule
Director Craft Engine does not reopen the screenplay to create a competing diagnosis.
If input evidence is ambiguous, preserve ambiguity and choose expression compatible with the credible interpretations.
