# Director Craft Engine — Craft Pipeline

```text
Scene Intelligence + Router
↓
Current Beat state
↓
Dramatic change
↓
Audience-readable change
↓
Minimum Necessary Expression
↓
Observable carriers
↓
Free-space preservation
↓
Shot Design handoff
```

## Rule
Never start with “what kind of scene is this?”

Start with:
- what changed,
- what the character is doing,
- what the audience must perceive,
- which behavior can carry that meaning.

## Handoff
Output intent and readable behavior only. Do not output shot execution.
