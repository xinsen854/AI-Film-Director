# Ensemble Cohesion Technique

Source status: **[DEMO — Tigran / latest Acting Director integration] [UNPROVEN HERE]**.

This is an **optional** ensemble-performance technique. It is not a new story authority, not a required Director Craft output object, and not a universal scene formula.

## Scene direction + motive

For a multi-character scene that contains individually credible performances but still reads as if the characters are acting in different scenes, the director may test two additional questions:

1. **Scene direction** — is there one shared behavioral direction the ensemble is collectively pushing toward in this scene (for example: keep the goodbye painless, preserve normality, avoid public escalation)?
2. **Motive** — what different supported fuel makes each character push that shared direction in their own way?

Scene direction is not theme, dramatic function, Reveal, or audience interpretation. Motive is not permission to invent hidden backstory.

## Authority boundary

Any scene direction or motive used here **must not override Story Authority**, the locked screenplay, Information Ledger, Scene Intelligence, character canon, or already-established relationship state.

If the source does not support a character motive, keep it `UNKNOWN`/unresolved rather than manufacturing one. If the ensemble already reads coherently through existing objectives, tactics, reaction, relationship behavior, and blocking, do not add this layer.

## Output boundary

Use the technique only to improve already-authorized observable performance through existing Director Craft fields such as dramatic action, reaction logic, relationship behavior, body baseline, business, or visible carriers.

Do not create a second `scene_direction` authority object, do not require fixed beat counts, and do not force every character to carry physical business.
