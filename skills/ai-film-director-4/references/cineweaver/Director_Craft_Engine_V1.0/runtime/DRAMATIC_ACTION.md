# DC-01 Dramatic Action

Ask what the character is **doing** in the current Beat, not what emotion they are displaying.

Read:
- objective
- obstacle
- tactic
- stakes

Translate into observable pursuit and resistance.

Useful outputs:
- pursuit behavior
- resistance behavior
- tactic persistence
- tactic failure
- tactic change
- decision behavior

An internal state is not itself a playable action. The expression should show the character pursuing, resisting, hiding, testing, delaying, persuading, avoiding, conceding, or changing approach.
