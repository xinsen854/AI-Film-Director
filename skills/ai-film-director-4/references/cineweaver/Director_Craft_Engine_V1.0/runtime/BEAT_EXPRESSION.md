# DC-04 Beat Expression

A meaningful **Beat change** must become visible or audible enough for the audience to perceive.

Possible markers:
- gaze shift
- breath change
- tactic change
- posture change
- action stops or resumes
- distance changes
- speech rhythm changes
- delayed response
- silence gains meaning
- object handling changes
- another character notices or reacts

The goal is **visible change, not explanation**.

Do not exaggerate every Beat. Select only the carrier that best reveals the actual change.
