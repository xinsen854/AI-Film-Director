# DC-06 Space & Rhythm

Use **space** and **rhythm** as dramatic meaning, not as shot instructions.

Consider:
- relationship distance
- approach / retreat permission
- spatial dominance
- entry / exit significance
- action density
- pause density
- reaction delay
- beat compression / expansion
- silence tendency

A **pause** matters only when it carries thought, pressure, resistance, or a Beat transition.
A **reaction delay** should be described relatively, not as fixed seconds here.
