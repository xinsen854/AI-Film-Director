# Minimum Necessary Expression

For every meaningful Beat, run this decision loop:

```text
What changed?
↓
What must the audience perceive?
↓
Which 1–3 observable carriers communicate it best?
↓
Leave everything else free.
```

## Why
Expression density is not acting quality. Too many simultaneous face, breath, hand, posture, and movement instructions can flatten performance into a checklist.

## Default
Prefer **1–3 high-information carriers** for an important Beat.

Examples of carriers:
- gaze hold
- interrupted hand action
- breath catch
- delayed reply
- body orientation change
- distance change
- object release

## Exception
More than 3 carriers may be justified only when the Beat is genuinely multi-character or physically complex and the additional carriers represent different necessary readable events rather than redundant emotional decoration.

## Free space
Always state what should remain **free space** when over-control is a risk.

Examples:
- normal blinking
- incidental hand movement
- ordinary breath variation
- non-critical facial motion
- background micro-behavior

The purpose is not minimal prose for its own sake. The purpose is maximal signal with minimal unnecessary control.
