# 04｜正式分镜 Skill V6.1｜V4.8内容质量强锁 + Seedance Current-GU

## 一、职责

04只负责读取：

```text
INTEGRATED_DIRECTOR_SCREENPLAY.md
ASSET_LIBRARY.md
```

将03已经确认的剧情、表演、调度、镜头意图和声音设计拆成正式分镜。

04不得：

- 修改剧情；
- 修改锁定对白；
- 增加人物、证据、道具或场景；
- 改变信息释放顺序；
- 改变03已经确认的场景结果；
- 重新导演；
- 自行创造资产编号。

## 二、唯一输出（ONLY OUTPUT）

```text

```

不再输出或要求上传：

```text

```

## 四、EDIT SHOT / PHASE / GENERATION UNIT

### EDIT SHOT
真实电影剪辑镜头使用三位编号 `SH001 / SH002 / ...`。镜头时长由叙事和剪辑需要决定，可以是3秒、6秒、8秒、13秒等，禁止为了填满模型窗口机械切成15秒或30秒。

### PHASE
一个连续 EDIT SHOT 内部需要分阶段描述时，使用 `PH01 / PH02 / PH03...`。PHASE 表达状态推进，不代表剪辑点。默认**不用完整逐秒时间轴**。

只有执行关键事件确实需要时间约束时，才增加少量【关键时间锚点】，例如某个动作必须后置、某句对白后必须停顿、某个关键揭示必须在末段发生。禁止为了显得详细而把整个15/30秒写成密集时间表。

### GENERATION UNIT
一次 Seedance/目标模型调用使用 `GU001 / GU002 / ...`。一个 GU 可以是 ISOLATED（单镜独立控制）或 MULTI_SHOT（安全打包多个短 SH，并以 HARD CUT 区分）。

模型窗口：Seedance 2.5 单 GU 最长30秒；Seedance 2.0 单 GU 最长15秒；OTHER读取 Model Adapter。
`15S / 30S_BLOCK / AUTO` 是生成组织策略，不是电影镜头时长。

### 资产预算
视觉/媒体资产预算按 GU 计算。V系列声音资产为纯文字，`seedance_reference_slot_cost=0`，永远不占图片/视频/音频参考素材数量。

## 五、资产调用

### 每个 EDIT SHOT 只调用当前镜头真正必要的视觉图片资产（V系列不计，不设全局固定数量上限）

每个正式 EDIT SHOT 最多调用6张视觉图片资产。V001/V002...声音资产是纯文字，不进入图片资产调用，不计入这6张，也不占Seedance素材数量。

一张人物三视图母板计为1张。

一张S场景六视图资产板计为1张。

一张P道具多视图板计为1张。

以下项目级通用继承不计入6个镜头专用图片资产：世界观文字规则、项目视觉风格、年代与技术等级、全局色彩与材质原则、人物面部安全处理规则，以及不需要单独上传图片的通用状态说明。04只能以文字继承这些规则，不得把它们重复创建为镜头资产。

视觉资产调用顺序固定为：

```text
A系列核心人物 → B系列持续次要人物 → G系列 → P系列关键道具 → S系列场景
```

V系列声音资产不进入图片资产调用行。V001/V002...只以文字声线进入【声音】，不得转换成@图片、@视频或@音频。

同一系列按编号从小到大排列。

### 连续技术片段

同一戏剧镜头因视频平台限制拆成连续片段A、B时：

- 共用当前GU真正必要且可复用的视觉图片资产；V系列纯文字声线不计；具体媒体容量只服从目标模型/项目Profile；
- 可以少用其中部分；
- 不得在片段B中增加第7张新资产；
- 必须新增核心人物、关键道具或更换S场景时，应重新拆成新的正式镜头。

### 图片尚未生成

当`ASSET_LIBRARY.md`中已经有正式编号，但图片状态为“待生成”时，允许调用：

```text
占位图：A001_NAME_CHARACTER_BOARD_V01.png
占位图：S001_NAME_SCENE_BOARD_V01.png
```

视觉占位图仍计入6张上限；V系列没有占位图。

04不得因为图片未生成而建立新编号或额外请求文件。

当03明确要求某个可复用人物、持续状态、关键场景或关键道具，而`ASSET_LIBRARY.md`中尚无对应正式编号时，04不得自行创建资产、状态编号或资产提示词。必须在同一个`STORYBOARD.md`中标记：

```text
缺失资产（MISSING_ASSET）
返回资产提取（RETURN_TO_ASSET_EXTRACTION）
所需资产：
来源剧集与场景：
缺失原因：
```

由05补充统一资产库后，再继续受影响的正式分镜。

### 人物板防复制规则

调用人物三视图母板时，视频生成提示词必须加入：

```text
资产板中的三个视图均为同一人物的参考。
正式画面禁止继承三宫格、拼贴、分屏、边框和标题条。
禁止把同一人物复制成多人。
只生成剧情规定数量的人物。
人物视觉、面部处理和整体风格严格继承统一资产库（ASSET_LIBRARY.md），04不得自行改写或重新定义。
```

### 场景板防污染规则

调用S场景多视图板时，视频生成提示词必须加入：

```text
场景板各视图均为同一场景的空间参考。
正式画面只采用当前镜头指定的功能区和视角。
禁止继承多视图拼贴、标题条、编号、文字、结构图和边框。
禁止生成场景资产板中的任何人物。
```

### 简单镜头

普通近景、正反打、静态对白和无空间变化的反应镜头，只写：

```text

```

```text
人物终点：

```

人物ID、朝向箭头、CAM、轴线、关键道具和出入口必须实际画在框内，不能只保留空框再把所有信息写在框外。该占位图直接写在`STORYBOARD.md`中，不单独生成文件；Renderer还必须把同一块原样插入所属GU最终Prompt。简单镜头不得输出该块。

## 七、六类镜头衔接

每镜结尾只选一种：

```text
CS｜状态接力：同一状态继续
RC｜反应切：从接收者即时反应开始
AR｜动作结果切：从动作结果已经发生开始
CC｜覆盖切：状态连续，只更换机位或景别
AB｜动作桥接：从同一动作推进后的阶段开始
ST｜场景转换：更换地点、时间或功能区
```

基本选择顺序：

1. 换地点或时间：ST；
2. 从另一人物反应开始：RC；
3. 直接跳到动作结果：AR；
4. 同一动作跨镜继续：AB；
5. 只更换摄影覆盖：CC；
6. 其余连续状态：CS。

换机位可以改变画面左右，但不得无理由改变人物在场景中的真实位置。

## 八A、字段内容质量强锁｜FIELD CONTENT QUALITY

V4.8-derived 栏目**存在不等于合格**。凡当前镜头有实际执行信息，该栏目必须写当前 SH/GU 的**具体、可观察、可执行事实**，禁止用模板套话完成字段。

### FIELD_BOILERPLATE｜硬失败
以下属于典型不合格写法，不能作为正式字段内容：

```text
当前动作中只锁定与功能直接相关的视线、停顿、手部状态或许可变化。
按资产库与连续性锁执行。
人物保持克制。
摄影按剧情需要处理。
声音按场景执行。
空间继承上一镜。
```

这些句子可以是内部原则，但不能代替本镜事实。Final QC 发现字段主要由此类套话构成时触发 `FIELD_BOILERPLATE`。

### 【摄影参数】质量
有摄影意义时至少写清当前镜头的：景别/距离、机位高度或相对位置、拍摄角度、摄影机行为、构图/焦点；具体焦段只在有执行价值时写。禁止只写“中近景、克制摄影”结束。

### 【空间与站位】质量
必须写当前镜头真实人物/道具位置和必要移动。不得复制整个 S 场景地图；不得写与当前镜头无关的其他人物位置。

### 【关键微反应】质量
当镜头承担人物表演/反应时，必须将上游导演事实转换为**可观察行为**，例如眼神停留与转移、眼睑、眉间、嘴角、下颌、鼻翼、呼吸、吞咽、肌肉紧张/松开、反应延迟、手部犹豫等。只选择真正承担戏剧信息的细节，不为“详细”而堆动作。

禁止用“悲伤、克制、愤怒、紧张”等情绪标签代替行为。`保持克制` 单独出现不构成表演指令。

### 【声音】质量
只写当前 SH/GU 能听到的声音及其远近、空间、叙事作用。不同场景的声音菜单不得复制到每镜。

### 【连续性锁】质量
只写当前 SH 必须保持的连续事实；未来事件、未来道具状态、其他场景的事实不得提前进入。

### 缺少图片参考
当前关键主体**缺少图片参考**时：不得假装已有参考图；在本镜/最终Prompt中从资产库展开必要的**文字视觉身份**。若一致性要求必须依赖图片而图片缺失，则标记 MISSING/FAILED 并交由 QC，而不是用“保持一致”遮盖。

## 八B、CURRENT_GU_ONLY｜最终Prompt隔离

`【Seedance最终视频生成提示词】`只编译当前 GU Member SH 的 active facts：
- 当前实际媒体参考；
- 当前人物/场景/道具；
- 当前初始状态；
- 当前动作、表演、对白、声音；
- 当前跨PH/跨Member SH必须保持的连续性；
- 当前高风险局部限制。

严禁批量复制：**未来事件、无关资产、无关声音、全局连续性**。当前 GU 没有关键时间事件时删除【关键时间锚点｜可选】。

最终参考绑定必须写成 Seedance 可执行形式，如 `@图片1 对应 A001...`；**内部编号不能替代媒体引用职责**。

## 九、条件触发内容

以下内容只有发生时才写，不为每镜重复填写“无”：

- 完整空间占位图；
- 形态变化与恢复；
- 特殊能力触发；
- 特殊感知机制；
- 项目专属世界规则；
- UI；
- 特殊镜头技术；
- 多线切换；
- 连续技术片段；
- 缺失图片占位；
- 缺失正式资产返回标记。

### 形态变化

发生形态变化时必须继承03并写清：

- 起始形态；
- 连续变化；
- 结束形态；
- 人物身份锚点；
- 服装与伤势继承。

禁止换脸、瞬间跳变和用烟雾强光遮盖关键变化。

### UI

只有剧情确实使用手机、终端、医疗设备、监控或权限系统时才写UI。

UI必须继承01锁定的年代、世界观、技术等级和视觉风格，不提前泄露幕后真相。
