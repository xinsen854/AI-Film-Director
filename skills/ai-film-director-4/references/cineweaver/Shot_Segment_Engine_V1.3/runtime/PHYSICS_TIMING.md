# PHYSICS / TIMING

Timing mode:
- FREE — no explicit timing.
- RELATIVE — preserve order, pause and reaction relationship.
- EXACT — precise timing is execution-critical; the internal Video Prompt Compiler may write second ranges or exact event times.

Do not use exact timing by default.

Physics is conditional and causal:
`force → contact → resistance/material response → inertia/body reaction → stable result`.

The structured storyboard decides the need; the internal compiler turns it into directly executable prompt language.
