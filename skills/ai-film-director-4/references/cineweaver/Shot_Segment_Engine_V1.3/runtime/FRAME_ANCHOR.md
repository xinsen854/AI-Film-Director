# FIRST / LAST FRAME ANCHOR

Frame anchors are conditional risk controls.

Strengthen first-frame specification when there is risk of:
- empty opening,
- late character appearance,
- wrong landmark relation,
- wrong action start state,
- prop/hand confusion,
- spatial flip.

Strengthen last-frame specification when next-shot continuity depends on:
- position,
- gaze,
- body orientation,
- prop state,
- wound/wardrobe state,
- action result,
- emotional tail.

Do not spend detail on frame anchors when the shot is simple and stable.
