# DIRECTOR CRAFT INTEGRATION

Consume `DIRECTOR_CRAFT_RESULT` rather than re-inventing performance psychology.

For each meaningful SHOT preserve:
- current Beat change,
- audience must-read event,
- primary/secondary readable information,
- usually 1–3 visible carriers,
- reaction logic,
- relationship behavior,
- free space.

The storyboard may choose coverage that makes the carriers readable. It should not add exhaustive micro-expression checklists when Director Craft did not require them.

## Optional FACS handoff

If Director Craft used FACS as a precision notation, Shot Design must preserve the underlying performance meaning and first consult the active model adapter / model profile. Emit AU notation only where that adapter explicitly permits the empirical FACS prompt heuristic. If the adapter does not permit it or AU notation is unreliable, compile the same carrier as short anatomical / observable behavior instead. **Do not drop** the Beat meaning merely because FACS notation is unavailable, and do not turn AU codes into provider parameters.
