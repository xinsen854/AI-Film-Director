# EDIT SHOT BOUNDARY

An EDIT SHOT is one uninterrupted editorial/camera shot between real cuts.

Start a new EDIT SHOT when:
- receiver reaction is intentionally cut to;
- action result/consequence is intentionally cut to;
- coverage angle/size changes through an edit;
- scene/time state changes;
- camera geography intentionally resets through a cut;
- an insert or cutaway becomes its own editorial image.

Do not create a new EDIT SHOT merely because:
- a Beat changes;
- a tactic changes;
- a reaction happens;
- the model has spare or insufficient nominal window.

After EDIT SHOTs are defined, a separate packing decision groups one or more compatible EDIT SHOTs into a Generation Unit.

Boundary question: **Would the finished film contain a cut here?** If yes, create a new EDIT SHOT.
