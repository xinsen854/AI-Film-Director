# OVERLOAD POLICY

Generation capacity is evaluated from the combination of:
- active character count,
- active visual asset count,
- action count,
- action complexity,
- dialogue density,
- physics complexity,
- spatial change,
- Beat count,
- PHASE count,
- selected duration profile.

When overloaded:
1. remove non-essential reference/control,
2. reduce simultaneous actions,
3. simplify blocking,
4. move secondary reaction to another SHOT if dramatically acceptable,
5. split the SHOT.

If repeated generations fail, simplify the SHOT before adding more wording.
