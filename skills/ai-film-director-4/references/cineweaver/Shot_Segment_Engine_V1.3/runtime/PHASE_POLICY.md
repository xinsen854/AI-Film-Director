# PHASE POLICY｜PHASE-FIRST, NO MECHANICAL TIMELINE

`PH01 / PH02 / ...` is a state/action/performance phase. It is not an EDIT SHOT boundary and never hides a cut.

There is **no fixed mandatory PHASE count**. Use only as many phases as the action, performance, information flow and final Seedance execution genuinely need.

Each PH may contain:
- stage goal;
- camera/image behavior;
- character action and physical causality;
- performance and microreaction;
- dialogue execution;
- end state.

The end state of one PH must be compatible with the next PH start state.

Default: do not write a full second-by-second timeline. Add `【关键时间锚点｜可选】` only when a specific event timing materially matters.

A true cut creates another EDIT SHOT or an explicit HARD CUT boundary in a MULTI_SHOT Generation Unit.
