# Scene Intelligence V1.0 — Boundary Rules

## Ownership

### Scene Intelligence owns
- scene meaning
- dramatic function
- interaction form
- character objectives
- emotional mechanism
- relationship change
- power/status change
- subtext
- information state
- space function
- energy diagnosis
- Beat changes
- generation risk identification
- confidence and ambiguity

### Capability Router owns
- which capabilities activate
- capability priority
- HARD / SOFT / FREE choice
- which information is forwarded downstream

### Director Method Library owns
- how the scene should be directed
- directing method selection
- scene-specific technique combinations

### Shot / Segment Design owns
- actual shot division
- framing choices
- camera placement
- camera movement
- coverage structure

### CineKernel owns
- low-level generation reliability
- minimum necessary control
- asset / performance / generation engineering constraints
- failure containment and local repair logic

## Hard exclusions from Scene Intelligence
Scene Intelligence does not choose focal length, FOV, camera position, composition,
lighting plan, shot count, shot/reverse-shot structure, final video prompt,
model parameters, or fixed style references.

Risk description is allowed.
Constraint selection is not.
