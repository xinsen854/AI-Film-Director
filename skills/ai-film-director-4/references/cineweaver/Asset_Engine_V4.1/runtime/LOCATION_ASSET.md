# LOCATION ASSET

S assets define **what the place is**, not how the current director shoots it.

Record:
- story function;
- reuse range;
- architecture type;
- material / color baseline;
- image file/status;
- view coverage;
- bird's-eye / spatial structure when useful;
- `stable_geography`;
- `landmark_anchors`;
- stable entrances / exits / fixed structures;
- functional zones;
- optional long-term lighting-direction baseline if it is genuinely architectural / environmental.

Asset Engine **does not decide camera** position, shot size, lens, current composition, current blocking, or current SHOT lighting treatment.

The location reference is geography / identity evidence. It must not force downstream framing.
