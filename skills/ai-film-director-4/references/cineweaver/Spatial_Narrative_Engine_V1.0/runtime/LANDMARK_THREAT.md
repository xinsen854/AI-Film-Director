# LANDMARK MEMORY / THREAT GEOGRAPHY

## Landmark Memory
Use a landmark only when it helps:
- establish orientation;
- signal a spatial loop / return;
- identify a zone without exposition;
- support later reveal / payoff;
- anchor continuity.

Examples:
- broken neon sign;
- red fire cabinet;
- unique column number;
- stairwell mouth;
- giant billboard silhouette.

## Threat Geography
Optional zones:
- surveillance zone;
- enemy sightline zone;
- audible exposure zone;
- safe pocket;
- bottleneck;
- controlled exit;
- dead angle.

Threat geography must derive from actual scene facts, not game-like decoration.
