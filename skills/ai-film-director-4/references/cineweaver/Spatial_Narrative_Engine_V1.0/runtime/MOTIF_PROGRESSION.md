# MOTIF PROGRESSION

## Purpose
Track a repeated visual entity only when the story already gives it accumulating meaning.

Possible progression:
```text
BACKGROUND PRESENCE
→ INFORMATION OBJECT
→ CONFLICT OBJECT
→ ACTION OBJECT
→ RELATIONSHIP / THEMATIC SYMBOL
→ MEANING THROUGH ABSENCE
```

## Rules
- Motif progression is optional.
- Repetition alone does not make a motif.
- The engine must not invent “poetic symbolism” to make a scene seem sophisticated.
- Every progression step must connect to a real Beat, relationship, information or action change.
