# REVEAL LEDGER

## Purpose
Plan when an already-existing person, object, building or landmark is:
- absent from frame;
- present but latent;
- partially revealed;
- readable;
- emphasized;
- paid off.

## Stages
`OFFSCREEN → LATENT → PARTIAL → READABLE → EMPHASIZED → PAYOFF`

This is not a mandatory linear ladder. Skip stages when appropriate.

## Definitions
- **OFFSCREEN**: exists in world, not in current frame.
- **LATENT**: visible enough to exist, not meant to draw attention.
- **PARTIAL**: edge / obstruction / fragment; recognition may be incomplete.
- **READABLE**: audience can identify the entity.
- **EMPHASIZED**: shot intentionally directs attention to the entity.
- **PAYOFF**: entity enters action, information or thematic fulfillment.

## Record
```yaml
entity_id:

```

## Hard rules
- Never reveal early if early readability breaks suspense / information order.
- PAYOFF should not appear as if the entity was invented at the last second when prior presence is narratively required.
- Do not create symbolic meaning unsupported by upstream story/director facts.
