# CineKernel V1.0 — Freeze Policy
**版本：1.0**  
**状态：FROZEN**

## 1. 冻结目的
避免 AI Film Director 在继续拆电影、换模型、加技巧时，底层原则不断漂移。

## 2. 冻结内容
以下内容默认不可直接修改：
- Core Principles
- 三大 Engine 的职责边界
- Capability ID 与默认启用策略
- Evidence Ledger 中已确认的 KEEP / ADAPT / CONDITIONAL 结论

## 3. 不冻结内容
以下允许持续更新：
- Model Profile
- Director Method Library
- Scene Intelligence 分类体系
- Capability Router 权重
- 风格库
- 具体镜头模板
- 具体 Prompt 编译语法
- 失败案例库
- 新模型参数

## 4. 修改 Frozen Core 的条件
只有满足以下任一条件才允许升版：
- 明确生产反证
- 多项目长期冲突
- 新模型范式导致底层原则失效
- 现有原则造成稳定、可复现的系统性失败

修改时必须：
1. 记录旧规则；
2. 写明反证；
3. 给出新规则；
4. 更新 Evidence Ledger；
5. 主版本升级（V1.x → V2.0）。

## 5. 版本纪律
- V1.0：当前冻结底盘
- V1.0.x：只允许拼写/格式修正，不改语义
- V1.1：允许新增不冲突能力，但不改变 Frozen Core
- V2.0：只有底层哲学或职责边界变化时才升级

## 6. 核心原则
> 新东西默认加在上层，不默认改底层。

CineKernel 是“地基”，不是“所有知识的仓库”。
