# 创作自由协议：让研究服务于创造，而不是接管创造

## 核心立场

深度案例不是模板库。它们的用途是让创作者看见更多选择、代价和例外。新作品应从自身的人物、处境、文化和形式中长出来，而不是从获奖片的结构中倒模。

## 只有四类内容可以锁定

1. 用户明确要求保留的事实、人物、结局或表达边界；
2. 授权、版权、安全和事实准确性边界；
3. 已经确认的项目连续性；
4. 真实制作条件，例如片长、预算、演员、场地和播出规格。

除此之外，结构、视点、节奏、类型、场景数量、情绪路径和结尾方式默认都是可变项。

## 先生成差异，再作选择

遇到关键创作问题时，不要立即套用最熟悉的解法。先在内部提出性质不同的路径，例如：

- 行动造成情绪 / 克制积累情绪 / 误解改变情绪；
- 观众先知道 / 人物先知道 / 双方都误判；
- 关系靠冲突显形 / 靠照料显形 / 靠回避显形；
- 结局完成和解 / 只完成承认 / 拒绝完成；
- 现实主义表达 / 类型化表达 / 形式化主观表达。

这些不是每次都要凑齐的选项，只是提醒 AI 不要把第一个答案误当成唯一答案。

## 使用案例的正确顺序

1. 先定义新故事真正的问题，不先选参考片。
2. 从人物的欲望、防御、关系债和现实压力中提出多个可行方向。
3. 只有遇到具体难题时，才检索案例中的抽象机制。
4. 检查机制成立所需条件是否存在；不存在就放弃，而不是补剧情迁就它。
5. 将机制换一种人物关系、社会语境和视听语法重新发明。
6. 做“来源遮蔽测试”：删去参考片名后，新选择仍应能由本故事自身解释。

## 可借鉴与不可借鉴

可借鉴：

- 压力如何逼出选择；
- 信息如何改变行为的意义；
- 关系如何通过代价发生位移；
- 一次事件如何沿着关系网传导，在不同人身上变成不同性质的反应；
- 表演、空间、声音、剪辑怎样共同改变观众体验；
- 某种机制在哪些条件下失败。

不可借鉴：

- 原作独特的人物组合和身份配置；
- 可辨认的情节链、反转顺序和场景设计；
- 标志性对白、动作、道具、空间或视听意象；
- 只因获奖而被误认为普遍正确的风格。

## 情绪不由标签生成

不要先写“这一场要感人、震撼、治愈”。先问：

- 人物此刻在保护什么尊严或自我叙事？
- 他想让对方做什么，却为什么不能直说？
- 他采取的防御短期帮了他什么，长期又毁掉什么？
- 这次选择让之后哪条路变得更难？
- 观众将从哪个可见行为理解到人物没有说出的部分？
- 事件结束后，谁还要承担余波？

情绪是这些条件共同作用的可能结果，不是指令词本身的结果。

## 情绪面的自由与纪律

床单模型是设计工具，不是必须填满的表格。一次事件不需要惊动所有人；重要的是知道谁被惊动、谁没有、以及为什么。

自由的部分：谁是受压点、力沿哪条关系传导、传导后变成什么性质的反应、谁按住不动、凹陷是加深还是被人抹平——这些都应由这个故事的人物关系决定，不应模仿任何参考片的配置。

纪律的部分：不要把同一个事件写成几个人平行的情绪；不要在没有关系张力的地方硬造反应；不要让人物互相解释这张面正在如何变形；不要在没有可见原因的情况下把凹陷恢复平整。

规模校准：短片和品牌叙事通常只承载一个受压点加一到两条传导线；长片和剧集可以让多张面互相叠加。压力点数量应由片长和人物密度决定，不由"越复杂越好"决定。

## 保留不完整与偶然

允许人物矛盾、退步、误解自己；允许一个场景同时滑稽和痛苦；允许母题不被解释；允许结局只解决行动而不解决人格；允许观众对人物保留不同判断。

但“开放”不能用来掩盖因果缺口。偶然可以制造压力，重大选择及其情绪后果仍应归属于人物。

## 去机械化审校

交付前逐项检查：

- 是否因为参考片如此，就让新故事也如此？若是，删除或重发明。
- 是否出现固定分钟、固定转折数、固定场景数的硬规定？若非用户或制作要求，删除。
- 是否所有人物都在为结构服务，却没有自己的判断和损失？重建人物能动性。
- 是否把复杂心理写成一句主题台词？改为行为、选择与余波。
- 是否只有一种“正确情绪”？保留至少一种合理的观众异议。
- 是否把不确定的解释冒充编剧意图？改为有证据等级的分析。
- 是否为了显得深刻而增加灾难？优先尝试更小但更具体的压力。
- 是否所有认同锚点都对同一场戏做出相同反应？若是，说明锚点没有真正分化。

最终选择不需要同时满足所有案例规律。它只需要对这个人物、这个故事、这个时刻成立。
