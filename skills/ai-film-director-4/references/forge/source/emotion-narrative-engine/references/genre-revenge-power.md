# 复仇与权力叙事类型校准

## 体验承诺

复仇/权力叙事常让伤害、资格、能力、升级与代价同时接受审视。诊断目标是追踪人物如何解释正当性、如何把他人卷入，以及观众何时重新分类其行动；不预设宽恕、赎罪、悔悟或道德净化。

## 诊断镜头

| 镜头 | 证据问题 |
|---|---|
| **伤害诉求** | 人物认为发生了什么损害、对谁造成、哪些事实获证、哪些属于解释？ |
| **正当性** | 人物、对手、盟友、制度与观众分别凭什么承认或拒绝行动资格？ |
| **升级** | 每次选择怎样收窄之后的可能、扩大目标、改变手段或制造新债？ |
| **共谋** | 谁提供信息、沉默、资源、许可或执行；他们知道什么，又承担什么？ |
| **代价** | 行动在身体、关系、制度、自我叙事或旁观者层面留下什么可观察后果？ |
| **道德重分类** | 哪项较晚选择或信息让观众重新判断先前的正当性、能力、受害或责任？ |

区分解释人物与为人物辩护。有效行动可以同时造成伤害；受害身份也不自动证明每种手段正当。观众快感、人物胜利与作品道德结论不得互相替代。

## 失效条件

- 伤害只作为复仇许可，没有具体关系、价值或持续后果。
- 对手只有阻挡功能，无法从自身证据解释其选择；这不要求等量责任。
- 升级只是规模变大，没有改变共谋、正当性、代价或行动空间。
- 能力被反复奖励，受影响者却没有具体存在，导致代价只停在宣言。
- 把惩罚、胜利、牺牲或死亡自动等同于情绪释放。
- 强迫人物获得救赎、宽恕或悔悟，或把拒绝赎罪自动判为弧线失败。

只在权力与正当性问题会实质改变当前诊断时使用本校准。结尾可以完成行动、暴露代价、维持共谋、拒绝结算或保留争议。
