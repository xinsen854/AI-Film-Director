# 喜剧类型校准

## 体验承诺

喜剧可以由期待与结果的错位、尊严压力、社会表演、语言、身体、节奏或重复中的变化产生。它不需要创伤、道德黑暗、反派、牺牲或悲剧结局来证明深度。

## 诊断镜头

| 镜头 | 证据问题 |
|---|---|
| **期待** | 作品通过规则、身份、任务、语气或先前行为建立了什么可辨识预期？ |
| **尴尬** | 谁知道失态、谁误读、谁可能目睹；暴露会损害哪种具体身份或关系？ |
| **尊严** | 笑点让人物如何保护、丢失或重新争取体面；作品是否只把弱势者当靶子？ |
| **重复中的变化** | 再次出现的动作、误解或句式是否改变知识、地位、策略、代价或关系？ |
| **释放** | 笑、承认、失败、逃脱或关系松动兑现了什么压力；释放后还留下什么？ |

先确定笑点的功能，再判断它与主线情绪是缓冲、遮掩、升级、反证还是关系测试。严肃后果与喜剧可以并存，但不能把语气切换本身当作因果。

## 失效条件

- 只有随机古怪或台词机智，没有被建立的期待和变化。
- 每次重复都停在同一关系状态，使观众先于作品完成理解。
- 尴尬没有身份、观看者或后果，只剩强迫人物受辱。
- 所有人使用同一种聪明声音，人物防御和地位差异消失。
- 用解释笑点、主题宣言或强制温情取消已经建立的喜剧机制。
- 为让喜剧“更深”擅自增加创伤、道德黑暗、反派、爱情或牺牲。

只在喜剧承诺会改变断点严重度、受众效应或修复风险时使用本校准。喜剧有效但不承担悲剧功能，不构成缺陷。
