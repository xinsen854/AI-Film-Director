# CARD｜解释尾注与视觉重估：《寄生虫》两版收尾

> **研究状态：`CARD`。**本卡只比较公开英文 FYC 稿与韩国发行成片的尾声机制；它不评价整部影片，不把英文 FYC 当作韩文最终拍摄稿，也不继承本地 `DEEP` 档案中的旧环境路由。

## 完整研究字段

| 字段 | 记录 |
|---|---|
| `research_status` | `CARD`；局部版本机制对照，不具备全片 `DEEP` 含义。 |
| `work_version_source` | *Parasite / 기생충*（2019）。剧本层为 144 页公开英文 FYC 稿；成片层为本地研究所用 131 分钟韩国发行版。主要本地证据：[深度研究](deep-case-02-parasite-zh.md) §1.7、§2 序列 51–53、§4、§6 档案 11与§9 启发式 7。 |
| `source_layer` | 英文 FYC 剧本证据、发行成片证据、页到银幕比较、已列主创语境与分析者解释分层；没有版本化受众/接受证据。 |
| `evidence_boundary` | 两版尾声内容为 `SUPPORTED`；解释过度、视觉重估与可能脱离为 `INFERRED`；版本化接受差异为 `UNKNOWN`。 |
| `format_culture` | 韩国黑色喜剧/社会惊悚长片；尾声依赖半地下住房、劳动/住房流动与父子义务的具体语境。英文 FYC 的翻译和版本身份限制持续适用。 |
| `intended_main_emotion` | 版本共同支持的目标是让基宇的希望与其现实可行性并存。哪一版“意在”更悲观属于 `INFERRED`；本卡不把分析者对切点的解释升级为创作者事实。 |
| `affected_characters` | 基宇作为计划制定者和儿子；困于宅内的基泽；失去家人的忠淑；已死亡却被父子计划叙事弱化的基婷；观众作为幻想与现实的分类者。 |
| `wound_or_protected_value` | 有证据的保护价值是基宇维持父子关系、恢复行动感和相信未来计划的能力；不由本卡推断童年暗伤或人格诊断。 |
| `key_turns` | 基泽以灯光写信；基宇无法直接回复；他设想学习、挣钱、买宅和父子重逢；FYC 回到山上并说明信无法送达，成片从幻想拥抱直接切回半地下室。 |
| `suppression_release` | 计划暂时压住失父、失妹与经济无路；幻想释放父子重逢愿望。FYC 用陈述限制该愿望，成片用空间回切重分类它，两者都保留余波。 |
| `relationship_field` | 基泽 → 基宇：把生存变成无法正常寄出的父信；基宇 → 基泽：以长期计划承诺解救。忠淑与基婷的损失在父子通信中相对失语，构成可保留的反读。 |
| `audience_state` | 观众知道计划尚未实现，却可能暂时按蒙太奇语法把买房/拥抱当未来事实。FYC 的语言说明通信不可能；成片的半地下回切把刚见图像重新归类为愿望。版本对真实受众差异的证据为 `UNKNOWN`。 |
| `causal_chain` | 现实无救父路径 → 父信建立关系债 → 基宇以长期计划恢复能动感 → 幻想上升并完成重逢 → 结尾证据检验计划 → FYC 以说明句标出不可送达，成片以空间回切显示条件未变 → 观众在希望与可行性之间重估。 |
| `page_to_screen_contribution` | FYC 页面提供父信、计划、幻想与回山陈述；成片压缩信/计划，并由暖阳拥抱到冷暗半地下的剪辑、光线、窗位和片尾声画完成最终分类。页面不能独占成片切点的效果。 |
| `counter_reading` | FYC 收尾并非冗余：它把“信无法送达”的父子关系事实说清，可能比视觉回切更重视通信断裂。成片回切也可能被部分观众读成过度明确的悲观句号，而非开放余味。 |
| `failure_conditions` | 观众尚未理解幻想语法；现实空间没有被充分建立；解释句新增必要因果而非重复；视觉回切只为嘲笑愿望；或交付媒介无法承载镜头/声音重分类。 |
| `transferable_mechanism` | 让角色的希望与最后一个可观察事实分属不同证据层，检查语言是否新增必要信息，或只是重复画面已经完成的重估。可以保留解释、改用视觉、或让二者故意冲突。 |
| `forbidden_imitation` | 不复制半地下室、豪宅、隐藏父亲、灯光 Morse、买房救父、上楼拥抱、山上眺望或相同切回构图。 |

## 弱效应字段

| 字段 | 记录 |
|---|---|
| `intended_effect` | 让父子愿望真实存在，同时不把个人奋斗计划误呈为已实现的经济路径。该效果由页面/成片比较支持；精确主创意图只在本地已列采访范围内陈述。 |
| `observable_design` | FYC 在幻想后回山并由基宇说明信无法交付；公映版在幻想父子拥抱后直接回到半地下室基宇，以空间和切点限制蒙太奇。 |
| `causal_break` | 不是已证明断裂，而是解释过度的局部弱风险：若观众已能从版本语法判断计划未实现，尾随说明可能把主动重估变成被告知结论；若语法不清，说明则承担必要因果。 |
| `likely_audience_detachment` | 在视觉证据已足够的条件下，部分观众可能从基宇的希望/自我防御转到作者解释，余波变得概念化；也有观众会因说明更清楚而保持投入。 |
| `alternative_causes` | 页面阅读与银幕观看天然不同；英文 FYC 可能不是拍摄稿；字幕、片尾歌、表演、窗位和发行载体都可能改变结尾理解，不能把差异只归因于一句说明。 |
| `reception_evidence` | `UNKNOWN`。本地 `DEEP` 未提供针对 FYC 收尾与公映回切的受众对照、测试数据或版本化接受研究。奖项、票房与总体评论不能填补该空缺。 |
| `smallest_repair` | 先验证最后一个可观察事实是否已让受众区分“愿望”与“实现”。若仍混淆，增加最小的事实限制；若已清楚，测试是否可减掉重复解释。也可保留语言以突出通信债，不把公映切点当唯一答案。 |
| `comparison_limit` | 仅比较公开英文 FYC 与发行成片的局部尾声；不能归因于韩文最终稿，也不能推出“视觉永远优于对白”或“开放结尾必须回到原空间”。 |
