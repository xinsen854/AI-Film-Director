# 诊断报告契约

## 正向输出结构

按以下顺序交付，让读者先看到边界，再看到因果与选择：

1. **输入精度与事实边界**：声明 `OUTLINE_COARSE`、`SCRIPT_FINE` 或 `MIXED`；列出关键 `LOCKED`、`SUPPORTED`、`INFERRED`、`UNKNOWN`。
2. **预期情绪承诺**：依据类型、语气、用户目标和材料说明作品希望观众经历什么；证据不足时标未知。
3. **多人物情绪账本**：汇总重要人物的欲望、保护价值、防御、选择、代价、余波和双向关系债。
4. **情绪关系场**：围绕重要事件并列人物与观众的知识、得失、解释、行为、相互影响、关系位移和携带后果。
5. **情绪面读数**：对最重的二到三个事件，写出承压点、传导路径、各主体位移在种类上的差异、谁在场却未位移及其后续代价、位移随时间加深或被拉平。材料不支持传导路径时写 `UNKNOWN`，不用因果套语填补。
6. **观众情绪路径**：说明已知、未知、误读、期待、恐惧、关心理由、意义变化、释放与余留；材料支持区分锚点时分锚点交付，并说明锚点之间如何相互牵动。
7. **情绪因果链**：展示得到证据支持的连接、隐含环节和断裂点。
8. **排序断点与待验证项**：正式断点使用分类代码和完整断点字段并合并同源症状；因输入缺失而不能确认的问题使用 `PENDING_*`，写明升级为断点所需的可观察条件，不赋予确定严重度。
9. **修复或验证方向**：始终交付本节。“只诊断”“不要改写”仍包含功能级方向，但不包含替代正文、场景或对白。证据支持改变时按修复契约列出最小方向；证据不支持改变时明确写“不建议改变”，并列出保持、观察或验证方向。
10. **设定保护与风险**：集中列出 `LOCKED`、连续性、批准需求和类型风险。
11. **置信度与未知项**：说明哪些结论最稳、哪些需更多材料验证。

当本报告被 `emotion-story-forge` 以 **AUDIT** scope 调用并用于最终锁定 HTML 时，在文字报告之外追加机器可读的：

- `narrative_topology`：连续/重置/混合，以及 story time / audience time 依据；
- `phase_events`：由状态变化聚合的阶段事件；
- `global_emotional_arc`：全剧情收束语义（summary、人物/观众 throughline、major turns、ending residue）；情绪河节点由渲染器从 `phase_events` 唯一聚合，不重复生成。

这些字段是同一审计结论的结构化副本，不是新增分析。

表格或短段落任选，以能清楚承载字段为准。不要为了整齐强迫每节具有固定条目数。

## 主张标准

让每个重大主张具备：`claim + source + boundary + confidence`。让每个高严重度主张再具备 `counter_reading`。若缺少来源，把主张改为 `UNKNOWN`。

将观众效应写成“在这些证据条件下可能……”；不要写成普遍心理定律。将粗粒度无法支持的场景级判断集中列入精度限制。

## 最终硬 QC

- 核对每个重大主张是否引用用户提供的材料或标为 `UNKNOWN`。
- 核对每个高严重度主张是否包含可信反向解读与置信度。
- 核对每个改变方向是否引用有证据的断点，并解释机制、保持项、条件、风险、设定影响和预期观众变化。
- 核对每个保持、观察或验证方向是否引用 `SUPPORTED` 的有效机制或 `UNKNOWN` 的证据缺口，写明目的与 `changes: none`，且没有制造断点。
- 核对修复或验证方向一节没有因“只诊断”“不要改写”或暂无明确缺陷而被省略。
- 核对任何改变用户提供事实的方向是否标为 `REQUIRES_APPROVAL`。
- 核对没有修复静默改变 `LOCKED` 或连续性。
- 核对粗粒度输入没有获得虚假场景、表演、对白、镜头或微节奏确定性。
- 核对粗粒度未提供的后续、代价、关系立场、地点原因、人物选择或结局被标为 `UNKNOWN` 或 `PENDING_*`，没有被直接写成高置信度缺陷。
- 若本轮纠正过人物或实体属性，核对标题、表格、关系词、代词、总结和方向全部使用统一称谓，没有残留错误别名。
- 核对没有固定幕、分钟、节拍、场景、转折、母题、情绪分数或角色数量处方。
- 核对没有复制案例的情节、台词、人物配置或标志性意象。
- 核对材料不足被呈现为限制，而不是被发明填补。
- 核对情绪面读数一节的每条传导路径引用材料中已建立的关系连线，未建立的写 `UNKNOWN`，没有用因果套语补全。
- 核对每个 `E11`–`E13` 断点包含 `pressure_point`、`expected_line`、`absence_type`、`deliberate_slack_reading`；`absence_type` 为“材料未提供后续”的一律降为 `PENDING_*`。
- 核对 `E13` 引用了至少两个由材料区分的观众锚点，没有为凑数虚构对立立场。
- 核对每个 `E11`–`E13` 修复方向包含 `surface_effect`，且优先加深或改道已有位移而非新增高强度事件。
- 核对分锚点的观众效应没有被压成单一反应，也没有把不同锚点写成同一句话的复述。
- 核对最终交付只包含诊断与修复/验证方向，不包含替代正文、场景、对白、续写、分镜、导演、资产生成或流程集成。
- 若用户要求 HTML，核对 HTML 与文本由同一份诊断数据生成，且没有新增事实、断点、分数、方向或确定性；若用户未要求，核对没有自动生成 HTML。
- 核对最终 HTML 所需 `phase_events` 没有按集数、场景数或固定六阶段机械切分，每个边界都能指出状态变化原因。
- 核对 `global_emotional_arc.aggregation_policy=derive_from_phase_states`，只引用存在的 `phase_id`，且没有独立重复输出人物/观众情绪节点。
- 核对人物与观众的情绪混合分别来自各自证据和知识状态，没有相互复制。
- 核对非线性或延迟揭露作品区分 story time 与 audience time；重置型作品没有伪造连续人物成长。
