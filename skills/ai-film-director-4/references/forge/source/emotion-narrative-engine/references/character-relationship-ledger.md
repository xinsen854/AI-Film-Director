# 人物与关系账本

## 人物账本

为每个被材料实质影响的重要人物记录以下字段；缺证据时写 `UNKNOWN`。

| 字段 | 内容 |
|---|---|
| `want` | 当下可辨识的目标 |
| `protected_value` | 人物试图保护的尊严、归属、控制、安全或其他价值 |
| `unspoken_need` | 有证据支持但未直说的需要；通常标为 `INFERRED` |
| `defense` | 面对压力的保护性策略 |
| `genuine_short_term_benefit` | 该防御确实解决了什么即时问题 |
| `choice` | 做出的行动、拒绝或延迟 |
| `cost` | 选择造成的自身或关系代价 |
| `aftermath` | 后续可观察残留 |
| `evidence_confidence` | 位置、事实标签与置信度 |

不要要求人物必须具备暗伤、创伤、牺牲或情感告白。只根据材料追踪其价值与策略。

## 双向关系债

对每一条重要关系分别记录 `A → B` 与 `B → A`，不要用单一“关系好/坏”标签抹平双方。

每个方向可记录：

- 已给予或拒绝的照料、承诺、保护、羞辱、义务或信任；
- 接收方是否知道、如何解释、是否承认；
- 债务如何影响当前选择；
- 已偿还、加深、转移、被否认或仍悬置的状态；
- 可观察的关系位移与被携带的后果；
- 证据位置、事实边界与置信度。

同一行动可以让一方认为债已偿还，让另一方认为债被加深。保留这种不对称，不强求共同结论。

## 联结到后文

将人物状态和关系债连接到可能的后续选择压力，但不要规定固定反应。使用条件句表达：“若后续要求 A 在公开忠诚与私人保护之间选择，则当前未偿债可能提高该选择的代价。”若材料没有后文，标为可检验方向，而非事实预测。
