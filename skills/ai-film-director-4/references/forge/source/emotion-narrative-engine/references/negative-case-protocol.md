# 弱效应与负向案例协议

## 定位

“弱效应”或“负向”只描述某个机制在指定版本、场段和证据条件下未充分产生预期效果，不是对整部作品、创作者或受众的笼统质量判决。同一作品可以在一个机制上较弱，在其他机制上有效。

添加、升级、引用或比较弱效应案例时读取本协议。个人不喜欢、感到无聊或偏好另一类型不属于接受证据，也不能单独建立负向案例。

完成当前故事的盲诊断后，才可按机制问题读取[弱效应案例索引](negative-case-index.md)。索引只路由到条件匹配的 `CARD`；不得按片名寻找批评，也不得把卡片中的开发版本差异升级为普遍处方。

## 必备分析字段

| 字段 | 要求 |
|---|---|
| `intended_effect` | 由用户目标、作品内承诺、营销定位或可靠主创陈述支持的预期效果；若只能推断，标明边界 |
| `observable_design` | 指定版本中可定位的动作、信息、选择、关系变化、重复或释放设计；剧本与成片分层 |
| `causal_break` | 明确链条在哪一环缺证、重复、错位或没有后果，不以“没感觉”代替因果 |
| `likely_audience_detachment` | 说明在这些证据条件下，部分观众可能如何保持距离、误读或失去期待 |
| `alternative_causes` | 至少一个竞争解释，例如文化位置、表演、发行语境、类型预期或材料版本差异 |
| `reception_evidence` | 来源、样本、时间、地区与方法边界；个人反应只能标为分析者体验 |
| `smallest_repair` | 只指出最小机制方向及其保持项、条件、风险与设定影响；不改写场景 |
| `comparison_limit` | 指明不能跨文化、媒介、预算、受众、版本或类型直接类推之处 |

同时记录 `work_version_source`、`source_layer`、证据位置、事实/解释边界、置信度、状态标签与禁止模仿项。样本卡仍须满足[研究语料协议](research-corpus-protocol.md)的完整字段。

## 建立流程

1. 先在当前故事中完成盲诊断；不要为了证明预设批评去搜“失败作品”。
2. 把问题缩小到机制和位置，例如“揭示未改变选择”，而不是“作品情感失败”。
3. 分开记录剧本设计、公映实现、页到银幕变化、主创陈述、接受证据与分析者解释。
4. 搜集能支持相反结论的证据；若替代原因同样有力，降低置信度或保留为待验证。
5. 按 `causal_break`、`likely_audience_detachment` 或待验证弱风险在索引中检索，只读取条件最接近的 `CARD`。
6. 只在条件可比时与正向案例对照；比较机制所需条件，不比较奖项、声望或个人喜好。
7. 提出最小可检验方向，并说明即使不修也可能成立的创作意图。

## 实际使用 CARD 时的报告披露

只有报告实际使用某张弱效应 `CARD` 来限定当前故事判断时，才随该判断披露以下内容：

| 披露项 | 报告内容 |
|---|---|
| `card_identity` | 卡片标题与真实研究状态 `CARD` |
| `qualified_claim` | 卡片正在限定当前故事的哪一项主张，并保留该主张的用户材料位置 |
| `source_evidence_boundary` | 所用版本/来源、证据层，以及事实为 `SUPPORTED`、解释为 `INFERRED` 或缺口为 `UNKNOWN` 的准确边界 |
| `reception_evidence_boundary` | 可用接受证据的来源和样本/方法限制；没有版本化接受证据时明确写 `UNKNOWN` |
| `counter_reading` | 能使弱效应判断降级、取消或改义的可信反向读法 |
| `comparison_limit` | 当前作品与卡片在文化、媒介、类型、版本或关系条件上不能直接类推之处 |

披露可以嵌入相关断点、证据注或案例对照，不规定篇幅、条目数量或独立章节。没有卡片与已证实问题条件匹配时跳过案例，也不产生这组披露；不得为了填报告而强行检索。

## 禁止推断

- 不把票房、奖项、评分、社交媒体热度或单条评论直接当作情绪机制的因果证明。
- 不把未看到的剧本设计归因给成片，也不把最终表演、调度、构图、声音、音乐或剪辑问题归因给剧本。
- 不以“多数观众”“文化就是如此”等无样本边界表述扩大接受证据。
- 不从负向案例复制其表面表达来“展示错误”；只提取因果断裂及其条件。
- 不把最小修复写成唯一正确答案；若证据不足，保留 `UNKNOWN` 或条件式验证方向。
