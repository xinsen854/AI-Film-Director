# 观众账本

## 记录单位

围绕证据变化记录观众状态。多数单元只有一个整体观众视角，可直接记录一组字段。但凡对应情绪关系场中的“同一重要事件”，必须先列出至少一组认同锚点（anchor）——按材料支持的立场、利益或人物认同划分，例如“认同 A 的观众”“认同 B 的观众”“未表态/中立位置的观众”——再分别为每个锚点记录以下字段，不得只写一句笼统反应把多个锚点压成一个点。

| 字段 | 诊断问题 |
|---|---|
| `anchor` | 该组观众更贴近哪个人物、立场或利益位置；材料不足以区分锚点时写 `SINGLE`，仍需说明为何暂不可分 |
| `knows` | 观众有何直接证据？ |
| `does_not_know` | 哪个关键缺口仍被保留？ |
| `misreads` | 作品是否有证据引导可修正的误读？ |
| `expects` | 哪项承诺、模式或因果让观众等待后果？ |
| `fears` | 哪种有根据的代价可能发生？ |
| `reason_to_care` | 观众为何在意人物、关系、价值或问题？ |
| `new_information` | 此单元增加了什么信息？ |
| `changed_meaning` | 新信息如何改写旧证据、选择或关系？ |
| `entry_detachment_release` | 观众何处进入、疏离或得到释放？ |
| `unresolved_residue` | 什么期待、债务或不安仍被携带？ |

## 锚点联动

同一事件下的多个锚点不是互相独立的平行反应，而是通过人物之间的 `relational_tension` 与关系位移彼此牵动：

- 说明至少一个锚点的 `reason_to_care` 或 `fears` 如何因情绪关系场中某主体的状态变化而被拉动，而不是各锚点各自成立；
- 若某锚点的反应会削弱、印证或重新分类另一锚点的反应（例如同情 A 者因新信息转向同情 B），在 `changed_meaning` 中注明这一转移，并给出证据位置；
- 材料只支持单一整体反应时，使用 `anchor: SINGLE` 并在 `changed_meaning` 说明当前证据为何尚不能区分锚点，不要虚构对立立场制造锚点数量。

## 因果要求

区分“增加事实”与“改变意义”。揭示只有在改变选择、关系、危险、先前证据的解释或未来预期时，才具有可说明的信息功能。惊讶本身不是功能证明。

把观众效应写成证据匹配的可能性，例如“由于 U03 在观众获得关心理由前先给出损失，部分观众可能保持观察距离”。不要声称所有观众必然产生同一感受。

## 强度与节奏

若强度标记有助于比较，可使用定性词或可选序位，但不得让分数替代压力、信息、选择、后果和重估的因果说明。不要规定固定钩子、转折、释放时点或情绪峰值数量。

在喜剧、悬疑和短篇中优先检查其体验承诺：误解是否演化、重复是否带来新变化、尴尬是否触及尊严、信息是否重分类、释放是否兑现已建立期待。不要为增加“深度”强加悲剧、创伤、反派、爱情或告白。
