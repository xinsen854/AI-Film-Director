# 盲诊断与断点分类

## 先盲诊断

先依据新故事形成候选问题，再查阅任何案例材料。不要从熟悉作品倒推当前故事应有的结构。分类是候选镜头，不是必填清单或发现配额。

先区分可观察问题与输入缺口。材料直接呈现问题，或用户确认完整可评估版本确实缺少相关功能时，才使用正式 `E*` 断点；仅因粗纲未提供后续而产生的疑问使用 `PENDING_*`，写明升级条件，不参与严重度排序。

## 分类

| 代码 | 诊断镜头 |
|---|---|
| `E01_AUDIENCE_ENTRY` | 痛苦或强事件出现时，观众尚无在意的理由 |
| `E02_CAUSAL_PREPARATION` | 情绪行动缺少足够的先行因果支持 |
| `E03_CHARACTER_AGENCY` | 压力发生，但没有带来有后果的选择或回避 |
| `E04_DEFENSE_VALIDITY` | 防御只有缺陷，没有真实短期收益 |
| `E05_RELATIONSHIP_DEBT` | 承诺、债务、照料、羞辱或义务被遗落 |
| `E06_INFORMATION_FUNCTION` | 揭示只增加事实，没有改变选择、关系或旧意义 |
| `E07_REPETITION_NUMBING` | 压力与反应重复，却没有有意义的条件变化 |
| `E08_RELEASE_FAILURE` | 释放相对已建立因果显得过早、过迟、失衡或无代价 |
| `E09_AFTERMATH_GAP` | 高点之后没有行为或关系余波 |
| `E10_MODE_MISMATCH` | 外加类型机制损害作品承诺的体验 |
| `E11_SURFACE_FLAT` | 重要事件只压动焦点人物，关系连线上本应被牵动的主体没有位移，或位移未被后续收取 |
| `E12_TRANSMISSION_ABSENT` | 多名人物同时反应，但各自反应彼此不相关：删掉最先承压者，其余反应仍原样成立 |
| `E13_ANCHOR_COLLAPSE` | 材料支持多个认同锚点，但同一事件在所有锚点上产生相同意义，观众差异被压成单一反应 |

## 报告字段

每个正式断点都写明：

- `source`：用户材料位置；
- `observed_problem`：可观察的结构或行为问题；
- `evidence_boundary`：`SUPPORTED` 或 `INFERRED`；若只能写 `UNKNOWN`，改为 `PENDING_*` 待验证项；
- `likely_audience_effect`：与证据匹配的可能效应；
- `counter_reading`：至少一个可信替代解释；
- `confidence`：高/中/低及原因；
- `severity`：高/中/低及其对作品情绪承诺的影响；
- `repair_scope`：行为、关系后果、观众信息或无需修复。

高严重度必须同时包含可信反向解读和置信度。若反向解读足以解释现状，将严重度下调或把结论改为待验证。

## 情绪面断点的额外纪律

`E11`–`E13` 断言的是“本应发生的位移没有发生”，属于缺席类主张，最容易在粗纲上被误判。除通用字段外，额外写明：

- `pressure_point`：该事件最先、最直接压在谁身上，引用材料位置；
- `expected_line`：依据材料中已建立的关系债或 `relational_tension`，力本应沿哪条关系连线传导到谁；没有已建立的连线就不能主张位移缺失，只能记 `PENDING_*`；
- `absence_type`：区分“材料呈现了该主体在场且无反应”（可作 `E11`/`E12`）与“材料未提供该主体的后续”（只能 `PENDING_*`）；
- `deliberate_slack_reading`：把静止读作设计而非缺陷的反向解读——不动本身可以是信息，只要作品后续向该主体收取代价；无法判断后续时下调严重度。

`E13` 需额外引用观众账本中至少两个已按材料区分的锚点；只有一个锚点或只能写 `anchor: SINGLE` 时，不成立此断点。不要为凑锚点数量虚构对立立场。

## 排序原则

按对作品自身情绪承诺的影响、因果传播范围与证据强度排序。不要按出现位置、类型惯例或个人偏好排序。将互为因果的多个症状合并到上游断点，避免重复计数。
