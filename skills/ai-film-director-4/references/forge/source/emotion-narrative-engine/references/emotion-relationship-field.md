# 多人物情绪关系场

## 分析单位

以“同一重要事件”为横截面，同时映射所有被实质影响的重要人物与观众。不要先画孤立人物曲线再猜彼此关系，也不要默认主角下降必然对应对手上升。把同一事件视为压向多个主体的一个面，而非分别落在孤立点上的多条曲线；各主体的凹陷深度由 `relational_tension` 与既有关系债共同决定，不只取决于事件本身的强度。

对每个主体记录：

| 字段 | 说明 |
|---|---|
| `knowledge` | 此刻知道、不知道或误解什么 |
| `relational_tension` | 该主体与本次事件、焦点人物或核心矛盾的关系距离、历史负债强度、利益关联程度；说明这次事件为什么在此人身上压得更深或更浅，不直接等同于感受强度 |
| `want` | 在该事件中的目标 |
| `gain_loss` | 事件结果实际带来什么收益、损失或未决变化 |
| `appraisal` | 主体如何解释事件；区分事实与推断 |
| `internal_possibility` | 材料允许的内在感受范围，不把它当可观察事实 |
| `observable_behavior` | 材料实际给出的行为；粗纲缺失时写 `UNKNOWN` |
| `effect_on_others` | 该状态或行为怎样改变他人的压力与选择 |
| `relationship_shift` | 信任、债务、权力、亲近或误读怎样位移 |
| `carried_consequence` | 什么被带入后续选择 |

将观众作为独立主体记录其知识与重估，不把观众情绪等同于任何人物。

## 关系模式

仅在证据支持时命名模式，并说明机制：

- **零和结果**：一方的明确所得来自另一方的明确损失；不要把所有竞争都简化为零和情绪。
- **负担或关系债转移**：事件把风险、义务、羞耻或照料责任移向第三方或未来。
- **情绪传染**：一方可观察的状态改变他人的解释或行为，而不要求感受完全相同。
- **公开/私人错位**：公开行为与有证据支持的私人解释不同；不要由沉默直接断言内心。
- **人物/观众错位**：观众掌握的信息让同一事件产生不同意义。
- **延迟重估**：后来的信息改变先前事件的意义；标明何种先前证据被重分类。

主角/对手跷跷板只是一种可选关系。多方可以同时获益、同时受损、暂时释然，或在不同维度上相反。

## 张力传导

不要孤立报告每个主体的 `relational_tension` 与 `effect_on_others`；说明它们如何沿关系连线彼此传导，使同一事件在多个主体上形成互相关联的凹陷面，而不是互不相干的点：

- 找出 `relational_tension` 最高的主体，说明其状态或行为如何改变至少一个其他主体的压力、解释或选择（写入对方的 `effect_on_others`）；
- 若某主体的凹陷因此被拉深、拉浅或转移（例如债务被代偿、羞耻被转嫁、情绪被稀释），在对方的 `carried_consequence` 或 `relationship_shift` 中注明传导来源；
- 观众不是单一凹陷点：不同认同位置的观众可能沿不同关系连线承受不同深度的传导，应在观众账本中对应记录，而非在此处压成一句笼统反应；
- 材料不支持传导路径时，写 `UNKNOWN`，不要用因果套语填补。

## 输出检查

对重要事件呈现主体之间的因果连接，而非平行情绪形容词。指出当前状态可能如何改变后续选择、关系债或观众期待；若后续材料不存在，使用条件式表述并给出置信度与替代读法。
## 人物质点可视化约束

最终情绪图谱中的粒子属于**人物可视化区域**，不再把整张 Canvas 网格误称为人物质点。一个人物可以由多个质点显示当前审计给出的情绪混合，观众使用独立区域。

- 质点可以把两个审计已给出的情绪家族画成同一圆内的渐变，并按关键帧权重连续改变占比。
- 质点大小、亮度、中心/边缘衰减、轻微漂移仅服务视觉层次，不生成新的心理结论。
- 人物之间的连接只显示审计已确认的关系变化或传导；并列反应不能自动生成连线。
- HTML 不从颜色、距离、速度或碰撞反推 `appraisal`、`relationship_shift` 或因果。
- 具体颜色、混合权重、关键帧和运动 token 使用 `adaptive-emotion-state-model.md` 契约。
