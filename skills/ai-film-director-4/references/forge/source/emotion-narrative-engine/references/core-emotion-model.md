# 核心情绪模型

## 叙事单元

让单元边界跟随作品中有意义的条件变化，不按固定幕、分钟、节拍、场景或转折数量切割。为每个单元记录：

| 字段 | 诊断问题 |
|---|---|
| `source` | 证据位于哪里？ |
| `observable_event` | 材料中实际发生了什么？ |
| `focal_character` | 谁承受或解释这一变化？ |
| `incoming_pressure` | 什么要求、威胁、欲望或信息进入？ |
| `choice_or_avoidance` | 人物做了、拒绝了或拖延了什么？ |
| `changed_condition` | 选择后，外部、内部或关系条件怎样不同？ |
| `carried_consequence` | 什么债务、风险、误解、期待或余波被带往后文？ |

把缺失字段标为 `UNKNOWN`。不要为了填表发明心理或事件。

## 情绪因果链

使用以下链条检查情绪是否由可追踪变化产生：

`pressure → interpretation → defense → choice/avoidance → changed condition → relationship/self shift → returning consequence → audience reappraisal`

让链条跨越实际需要的多个单元。证据允许观众自行推断时，可将某环节标为“隐含但受支持”；不要要求所有环节都被台词说明。

## 诊断方法

1. 从可观察事件开始，避免先贴情绪词。
2. 区分压力本身与人物对压力的解释。
3. 检查防御是否带来真实短期收益；纯粹缺陷通常会削弱可信度。
4. 检查选择或回避是否改变条件，而非只重复感受。
5. 检查关系或自我位移是否在后续行为中留下痕迹。
6. 检查回返后果是否让观众重新解释先前信息。

不要把因果链变成故事公式。链条可以开放、断裂、延迟或多义；诊断的任务是说明证据支持的连接与缺口。
## 状态变化驱动的阶段聚合

`叙事单元` 是证据采集粒度，`phase_event` 是语义聚合粒度，两者不要混为一谈。先按可观察条件变化建立细单元，再把连续单元比较为 `STATE BEFORE → causal events → STATE AFTER`。只有当人物/观众的认知、目标、关系、处境/选择空间、价值判断、行为策略或不可逆后果发生实质变化时，才建立新阶段。

如果连续事件只改变同一状态的强弱，不必新建阶段；在同一阶段的 `keyframes` 中记录变化。阶段数量、范围和名称全部由当前作品证据决定。

## Story Time 与 Audience Time

对非线性、悬疑、闪回、延迟揭露和信息差结构同时维护：

- `story_time`：故事世界实际发生顺序；
- `audience_time`：观众被展示、误导、提问与回收的顺序。

人物的解释与情绪只能依赖其当时可获得的信息；观众路径只能依赖实际呈现给观众的信息。后来揭露可以重估先前事件，但不得把后见之明倒灌成角色当时已经知道。



## 开放语义情绪原则

诊断不把“喜悦/兴奋/喜欢/希望/平静/惊讶/焦虑/恐惧/愤怒/羞耻/悲伤/厌恶”当成封闭心理分类。它们只作为稳定视觉基色。具体人物状态应优先使用材料最准确的语义词，并通过 `family` 或 `blend` 映射到视觉家族。

例如“内疚”与“羞耻”可以共享部分视觉成分，但如果证据表明人物是在为自己的选择或疏忽承担责任，就不要为了色谱方便把它强行命名成“羞耻”。同样，怀旧、释然、嫉妒、敬畏、眷恋等均可成为开放语义状态。

每个推断性情绪尽可能标记 `evidence_level` 和 `confidence`。材料只支持行为而不支持明确内心时，宁可标为 `INFERRED/low` 或 `UNKNOWN`，不要用百分比制造假精确。
