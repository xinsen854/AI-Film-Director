# CARD｜制度判决与关系债兑现：两版《逃出绝命镇》结局

> **研究状态：`CARD`。**本卡只比较公共早稿监禁结局与公映版 Rod 救援结局的局部机制，不评价整部影片好坏，不继承本地 `DEEP` 档案中的任何旧技能路由。

## 完整研究字段

| 字段 | 记录 |
|---|---|
| `research_status` | `CARD`；局部版本机制对照，不具备全片 `DEEP` 含义。 |
| `work_version_source` | *Get Out*（2017）。剧本层为本地 `DEEP` 档案核验的 100 页公共早稿；成片层为 Universal 公映版。主要本地证据：[深度研究](deep-case-04-get-out-zh.md) §7 档案 8、档案 11及来源 8–14、18。 |
| `source_layer` | 剧本证据、发行成片证据、页到银幕比较、主创陈述、早期测试接受口述与分析者解释分别记录；测试口述不升级为原始受众数据。 |
| `evidence_boundary` | 版本事件为 `SUPPORTED`；关系债、释放差异与可能脱离为 `INFERRED`；未公开测试方法为 `UNKNOWN`。 |
| `format_culture` | 美国社会惊悚/恐怖长片；结尾依赖美国黑人自卫、警务与证词可信度的历史语境。离开该语境，红蓝灯未必触发同一制度预判。 |
| `intended_main_emotion` | 早稿的系统性窒息由页面与本地分析支持；公映版先触发制度恐惧再释放，且 Peele 关于“英雄获胜/正向释放”的陈述由本地一手来源支持。二者都不是跨观众的必然效果。 |
| `affected_characters` | Chris 的身体自主、逃生能动性与讲述权；Rod 的朋友义务、调查行动与可信度；Rose 对制度偏向的预期；观众对警灯和救援的解释。 |
| `wound_or_protected_value` | 只记录有行为证据的保护价值：Chris 保护身体自主与自身证词，Rod 保护朋友并证明其直觉能转化为行动。未以本卡证据推断额外心理暗伤。 |
| `key_turns` | Chris 把行程和狗托付给 Rod；Rod 持续联系、查失踪、录音并报警；早稿让真实警察逮捕 Chris、Rod 隔监狱玻璃追问；成片让警灯触发举手后揭示 Rod 到场。转折由条件变化界定，不是结局模板。 |
| `suppression_release` | 前半将 Rod 的正确方向包装成笑话并延迟其效力；早稿把释放压进监禁后的伦理平静，公映版则让具体伙伴行动兑现关系债。两种释放对象不同。 |
| `relationship_field` | Chris → Rod：托付与求证；Rod → Chris：持续追查与实际到场。早稿保留关心却阻断行动回报；公映版让友情债改变 Chris 的外部条件。制度、Rose 与观众分别对“谁会被相信”持不同预期。 |
| `audience_state` | 观众先看见 Rod 的行动证据；警灯出现时调用早先盘查、警局笑场与文化知识预测逮捕；版本差异决定该预测被制度确认，还是被具体伙伴改写。 |
| `causal_chain` | 朋友预警被当笑话 → 异常信息传到外界 → Rod 的解释虽夸张但促成调查 → 制度嘲笑不终止行动 → Chris 独自逃出并触发警灯预判 → 早稿由监禁封闭，公映版由 Rod 到场兑现 → 观众分别获得制度判决或关系释放。 |
| `page_to_screen_contribution` | 公共早稿提供监禁、探视与口哨收尾；成片重写 Rose/Chris 公路对峙、举手、TSA 车和 Rod 接走。表演、灯光揭示、剪辑停顿与最终释放属于成片贡献，不能归给早稿。 |
| `counter_reading` | 早稿并非“错误结局”：它让 Chris 做对一切仍被系统吞没，具有更冷峻的伦理一致性。公映版也可能被读为概率很低的救援便利；若 Rod 前置行动不足，这一反读会增强。 |
| `failure_conditions` | 新故事没有可追踪的外援行动；受众不共享被触发的制度默认；救援只靠偶然；关系债并非作品承诺；或制度性无路本来就是目标效果。 |
| `transferable_mechanism` | 在结尾先激活受众有证据的默认结果，再由早已行动的关系主体制造具体例外；或有意让制度结果成立，并承认它将截断哪些关系回报。迁移的是“准备—预判—兑现/截断”，不是救援情节。 |
| `forbidden_imitation` | 不复制黑人主角、白人女友共谋、身体窃取、红蓝灯、TSA 车辆、机场朋友救援、监狱探视或具体台词/动作组合。 |

## 弱效应字段

| 字段 | 记录 |
|---|---|
| `intended_effect` | 早稿：让系统性不公盖过个体逃生；公映版：让观众先经历该恐惧，再以具体伙伴胜利提供释放。前者以页面与解释支持，后者另有主创陈述支持。 |
| `observable_design` | 早稿让真实警车、逮捕、监狱探视接续逃生；公映版让 Chris 举手、Rose 预期获救、车辆身份揭示与 Rod 到场接续逃生。 |
| `causal_break` | 不是已证明的普遍断裂。局部弱风险是：当 Rod 的连续行动已经构成关系承诺时，监禁结局使该行动无法改变条件，支线从因果参与者退回见证者；若目标本就是“行动仍无效”，则这不是断裂。 |
| `likely_audience_detachment` | 在等待外援行动兑现的证据条件下，部分观众可能把监禁读成主题对人物因果的覆盖，并从逃生能动性中退出；制度悲剧受众则可能因此更投入。 |
| `alternative_causes` | 测试反应可能受当时政治气候、类型营销、喜剧/恐怖语气、临时剪辑完成度或观众构成影响；不能把反应只归因于关系债。 |
| `reception_evidence` | 本地 `DEEP` 所引 [Vulture 主创口述史](https://www.vulture.com/article/get-out-oral-history-jordan-peele.html) 记录早期暗结局测试和补拍过程；[Vanity Fair 结局访谈](https://www.vanityfair.com/hollywood/2017/03/jordan-peele-get-out-ending)记录 Peele 的结局说明。限制：均非公开原始测试数据，缺样本量、人口结构、问题设计和完整版本控制。 |
| `smallest_repair` | 先验证结尾是否承诺让关系行动改变条件。若是，检查外援是否已有独立行动和代价；若不是，保留制度结局并明确关系线为何只能见证。无需自动增加救援、改成快乐结局或复刻公映版。 |
| `comparison_limit` | 只比较同一项目的公共早稿与公映版，不能证明“观众总需要胜利”，也不能直接迁移到不同警务历史、类型承诺、受众知识或没有伙伴支线的作品。 |
