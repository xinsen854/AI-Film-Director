# 最小修复契约

## 选择方向

始终交付修复或验证方向一节，把它视为诊断的一部分。“只诊断”“不要改写”仍要求这一节；它只排除替代正文、场景和对白。

针对已证实的断点寻找最小充分改变。只给出实质不同且可行的方向，不固定选项数量，也不要求必须改变。允许调整：

- **可观察行为**：改变人物如何选择、回避、保护或承受后果；
- **关系后果**：让承诺、债务、权力、信任或余波被携带；
- **观众信息**：改变观众何时知道、误读或重估，但不规定固定时点；
- **情绪面位移**：改变力沿哪条关系连线传导、被谁承受、在谁身上被拉深或拉平。

修复 `E11`–`E13` 时优先加深或改道已有位移，而不是新增压力事件；优先把并列反应重建为传导，而不是给每个人各写一次感受。修复方向只描述位移与后果的功能变化，不写替代场景。

若证据不支持改变，明确写“不建议改变”，并给出保持现有机制、观察后续证据或验证观众效果的方向，不制造断点。不要自动增加死亡、疾病、背叛、怀孕、牺牲、童年创伤或其他高强度事件来制造情绪。任何改变用户提供事实或引入新事实的方向都标为 `REQUIRES_APPROVAL`，保持假设状态。

## 改变方向字段

| 字段 | 要求 |
|---|---|
| `changes` | 精确说明将改变的功能、行为、关系后果或信息条件；不写成替代场景 |
| `remains` | 列明保持不变的 `LOCKED`、连续性、类型承诺和关键设定 |
| `mechanism` | 解释该改变如何修复已定位的因果缺口 |
| `conditions` | 说明成立所需的已有证据或待用户批准的新事实 |
| `risk` | 说明可能造成的类型、节奏、人物或原创性风险 |
| `canon_impact` | 标为无、低、中、高，并解释与锁定事实的关系 |
| `expected_audience_change` | 以可能性说明观众进入、期待、重估、释放或余留如何变化；涉及多个锚点时分锚点说明，不压成一句 |
| `surface_effect` | 仅 `E11`–`E13` 修复方向必填：说明改变后力沿哪条关系连线传导、哪些主体的位移被拉深或改向、谁仍然静止且后续如何被收取代价 |

## 保持、观察或验证方向字段

| 字段 | 要求 |
|---|---|
| `purpose` | 标为 `PRESERVE`、`OBSERVE` 或 `VALIDATE`，说明维持或检验什么 |
| `basis` | 引用证据支持的有效机制；材料不足时标为 `UNKNOWN`，不虚构断点 |
| `changes` | 固定写 `none` |
| `remains` | 列明要保护的事实、机制、类型承诺和连续性 |
| `conditions` | 说明观察什么，以及什么新证据才触发重新诊断 |
| `risk` | 说明保持现状或证据不足可能留下的风险 |
| `canon_impact` | 写 `none`；若方向实际需要改变事实，则改用改变方向并标 `REQUIRES_APPROVAL` |
| `expected_audience_change` | 写预期保持不变的体验，或验证要观察的可能效应 |

## 边界检查

在交付前按方向类型验证：

1. 让改变方向直接对应一个有证据的断点，并解释如何修复因果缺口。
2. 让保持、观察或验证方向引用一个 `SUPPORTED` 的有效机制或 `UNKNOWN` 的证据缺口，写明目的和 `changes: none`，不制造断点。
3. 不静默改变 `LOCKED` 或既有连续性。
4. 不强制幕数、分钟、节拍、场景数、视角、情绪轨迹、母题数、类型表达或结局。
5. 不包含替代对白、改写场景、续写、分镜、导演或资产提示。
6. 若方向需要改变用户事实或引入新事实，标为 `REQUIRES_APPROVAL`。

允许“移除”“整合”“有意去中心化”等方向并存，前提是各自机制与条件确实不同；不要为凑数制造差异。
