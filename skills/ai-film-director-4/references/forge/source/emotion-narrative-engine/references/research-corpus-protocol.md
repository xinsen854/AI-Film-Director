# 情绪叙事研究语料协议

## 定位

本技能保存并按需读取结构化研究资料；它不会重训练、微调或改变模型权重。研究资料只能为已经由用户材料证明的诊断问题提供对照证据，不能替新故事规定结构，也不能取代盲诊断。

在扩充语料、引用案例或提升案例状态前读取本协议。先完成当前故事的候选断点、证据位置、受众效应、反向解读与置信度，再决定是否查阅案例。

六份字节一致的历史研究中保留的旧技能名、`deep-analysis-standard.md` 等标准名仅是来源注记，不是本技能的路由指令。这些注记不得触发外部文件读取、技能调用或依赖；案例在本技能中的证据分层、状态含义与使用条件一律以本协议及本地引用为准。

## 六层证据

逐项标明来源层，不把不同媒介阶段合并成一个“作品证明”。

| 证据层 | 可以支持 | 不能单独支持 |
|---|---|---|
| **剧本证据** | 可得版本中的场景进入/退出、动作、对白功能、揭示顺序、关系铺垫、压抑/释放与携带后果 | 最终表演、调度、构图、声音、音乐、剪辑或公映结构 |
| **公映成片证据** | 正式发行版本中的表演、调度、构图、声音、音乐、剪辑及最终观众信息 | 原剧本写了什么、某效果由编剧预先规定，或早期稿本结构 |
| **页到银幕比较** | 已核验剧本版本与指定公映版本之间的保留、删除、增加、调序及贡献差异 | 无法获得的稿本、未记录的创作意图或单一工种的独占归因 |
| **主创陈述** | 说话者在明确时间与语境中的自述、目标或过程回忆 | 作品唯一含义、全部观众反应或未经独立核验的事实 |
| **观众/接受证据** | 有来源和样本边界的评论、调查、票房、奖项、长期讨论或特定群体反应 | 普遍心理定律、单一观众的代表性或机制因果的自动证明 |
| **分析者解释** | 基于前述证据的机制推断、反向读法与迁移条件 | 可观察事实、主创意图或真实接受情况 |

剧本单独不能证明最终表演、调度、构图、声音、音乐或剪辑。公映成片单独不能证明原剧本具体规定了什么。每项结论同时写 `source_layer`、版本、证据位置、事实/解释边界与置信度；证据冲突时并列呈现，不以流畅叙述抹平差异。

## 研究状态标签

标签描述已完成的证据工作，不描述作品质量，也不能因名气自动升级。

| 标签 | 实际含义 | 可用范围 |
|---|---|---|
| `INDEX` | 仅有可核验的样本/片目登记或研究队列位置 | 发现候选样本；不得作页码、场面或机制细节主张 |
| `CARD` | 有来源边界的简短机制卡，包含迁移条件和失效条件 | 为已诊断问题提供有限机制对照 |
| `STUDY` | 已选定并开展研究，但尚未通过全部深度案例闸门 | 使用已核验部分，并显式说明缺口 |
| `DEEP` | 已完成全片/全序列覆盖、人物关系、观众信息、因果、反证、迁移边界，以及可用时的页到银幕比较 | 在严格条件匹配下引用完整案例研究 |

文件名、篇幅、奖项或分析自信都不能把 `INDEX`、`CARD` 或 `STUDY` 变成 `DEEP`。状态下降时保留原因和日期；状态提升时记录通过的证据闸门。

## 样本卡必备字段

每张新卡或既有卡升级必须支持以下字段。缺证据写 `UNKNOWN`，不得为了填表补写人物心理或创作意图。

| 字段 | 要求 |
|---|---|
| `work_version_source` | 作品、年份、所用剧本/成片版本、来源、访问或核验日期 |
| `format_culture` | 媒介与时长类别、语言/地区、相关社会位置；避免把文化行为普遍化 |
| `intended_main_emotion` | 只在用户目标、作品证据或主创陈述支持时记录；区分推断与陈述 |
| `affected_characters` | 被机制实质影响的人物，以及各自不同的知识、得失和解释 |
| `wound_or_protected_value` | 只有反复行为、选择、后果或可靠陈述支持时才记录暗伤/保护价值；否则 `UNKNOWN` |
| `key_turns` | 由有意义的条件变化界定，不套固定幕、分钟、场景或转折数量 |
| `suppression_release` | 什么被压抑、延迟、承认或释放；写清准备、代价和余波 |
| `relationship_field` | 同一事件中多方的关系债、权力、信任、距离与相互影响 |
| `audience_state` | 观众已知、未知、误读、期待、危险判断、进入、脱离、重估与余留 |
| `causal_chain` | 压力、解释、防御、选择/回避、条件变化、关系/自我位移、回返后果与观众重估 |
| `page_to_screen_contribution` | 剧本与公映成片分别贡献什么；缺少任一层时说明不可比较 |
| `counter_reading` | 至少一个能解释同一证据的可信替代读法及削弱证据 |
| `failure_conditions` | 机制在何种人物、文化、媒介、信息或制作条件下失效 |
| `transferable_mechanism` | 去除原作专属表达后仍成立的条件—选择—代价关系 |
| `forbidden_imitation` | 不得迁移的情节链、台词、人物配置、标志性物件、空间、声音或影像表达 |

## 扩充与使用流程

1. 记录研究问题和它对应的已证实断点；没有诊断问题时不检索案例。
2. 核验作品、版本、来源和证据层；保存分析性抽象与链接，不捆绑剧本正文。
3. 填样本卡并把事实、解释、未知项分层；给主要主张补反向读法。
4. 按完成度赋予 `INDEX`、`CARD`、`STUDY` 或 `DEEP`，不得预授高级标签。
5. 使用时检查机制条件、文化语境、媒介阶段、类型承诺和证据分辨率是否匹配。
6. 执行来源遮蔽测试：拿掉片名后，方向仍须由新故事自身的人物与处境解释；若仍可辨认地复制原作表达，放弃该对照。

案例只能提高、降低或限定某项诊断的置信度。它不能把 `UNKNOWN` 变成新故事事实，不能以获奖或接受信号取代因果证明，也不能自动生成修复处方。
