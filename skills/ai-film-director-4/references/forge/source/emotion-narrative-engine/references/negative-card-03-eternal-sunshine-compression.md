# CARD｜过度决定与受控歧义：《暖暖内含光》的信息压缩

> **研究状态：`CARD`。**本卡只比较已核验发展/拍摄材料与公映版中 Mary 背景及走廊结尾的局部信息密度；它不评价整部影片，也不把未标日期第一稿当作最终拍摄意图。

## 完整研究字段

| 字段 | 记录 |
|---|---|
| `research_status` | `CARD`；局部版本机制对照，不具备全片 `DEEP` 含义。 |
| `work_version_source` | *Eternal Sunshine of the Spotless Mind*（2004）。剧本层以 2003-02-04 Goldenrod Revision / 2002-11-06 Shooting Draft 为主；未标日期第一稿仅作 B- 级发展方向；成片层为 Focus 公映版。主要本地证据：[深度研究](deep-case-03-eternal-sunshine-zh.md) §2.2–2.3、§7.8、§7.10与§9。 |
| `source_layer` | 修订拍摄稿、B- 级发展稿方向、发行成片、页到银幕比较、主创陈述与分析者解释分层；没有版本化受众/接受证据。 |
| `evidence_boundary` | 已记录的版本/删减事实为 `SUPPORTED`；过度决定、受控歧义与可能脱离为 `INFERRED`；版本化接受差异为 `UNKNOWN`。 |
| `format_culture` | 美国爱情/记忆科幻长片，采用精品厂牌浪漫喜剧语法与非线性主观形式；数据同意、职场权力和亲密关系的伦理读法受时代与受众位置影响。 |
| `intended_main_emotion` | Mary 线意图的精确强度为 `INFERRED`；结尾的开放性有 Kaufman 同期访谈支持。公映版让伦理不适与希望/复发并存，不证明所有解释性材料都应删。 |
| `affected_characters` | Mary 的知情同意与自我叙述；Howard 的专业/关系责任；Stan 的知情与回避；Joel/Clementine 对旧录音、失败预期与再次选择的处理；观众对“反派”“成长”和未来的分类。 |
| `wound_or_protected_value` | 有证据的保护价值：Mary 对自身历史、同意和档案控制的权利；Joel/Clementine 不被最坏录音完全定义、仍保有选择权。未由本卡诊断额外创伤。 |
| `key_turns` | Mary 搜档并听见自身历史；较完整材料含更长 Stan/Howard 内容与更黑暗背景；成片保留妻子揭露、Howard 承认和 Mary 取档；结尾较长录音/谈话在成片被压缩为受伤、离开、叫停、预告失败、两个“好”与雪地轻微循环。 |
| `suppression_release` | 更完整材料通过罪证和说明释放伦理确定性；成片压低确定性，让行为、档案与窗口权力承担意义。结尾压缩掉较长靠近过程，以表演和循环同时释放希望并保留复发余波。 |
| `relationship_field` | Howard → Mary：掌握她被删历史却继续享有崇拜；Mary → 客户：归还档案也未经再次同意。Joel ↔ Clementine：各自最坏录音打破理想化，但新的“好”只改变此刻退出选择，不偿清旧债。 |
| `audience_state` | 较完整罪证会更早把 Howard 分类为明确施害者；成片让观众在个人越界与制度化信息不对称间权衡。较长结尾更说明二人如何靠近；成片让观众从两个“好”和循环画面判断希望、无奈或复发。 |
| `causal_chain` | 信息不对称 → Mary 重复吸引并越界 → 历史揭示 → 更完整罪证可迅速封闭责任解释／公映压缩保留结构性共谋 → Mary 取档并重分配信息 → Joel/Clementine 被录音攻击 → 较长谈话可解释重新靠近／公映压缩让一次选择承受不确定 → 观众保留竞争读法。 |
| `page_to_screen_contribution` | 拍摄稿可证 Mary 搜档、更长 Stan/Howard材料及更长录音/走廊谈话；AFI 档案支持更黑暗 Mary 背景被删。成片的窗口调度、短促崩塌、停顿、笑/哭与雪地循环由导演、表演、摄影和剪辑共同完成。 |
| `counter_reading` | 更完整材料可能不是过度解释：它能明确同意受损的严重度，防止“复杂”软化 Howard 责任；较长结尾也可能为两人的再次选择补足必要准备，使“好”不显突兀。 |
| `failure_conditions` | 省略会让基本因果或同意事实不可理解；受众缺少必要伦理背景；表演/形式无法承载歧义；开放只来自作者未决定；或交付目标要求更明确的事实责任。 |
| `transferable_mechanism` | 区分“说明必要事实”与“替观众完成伦理/未来判断”。保留建立责任所需的最小事实，把仍可竞争的意义交给行为、关系后果或形式；也可有意选择更明确版本并承担其解释收窄。 |
| `forbidden_imitation` | 不复制记忆删除公司、被删恋情、流产暗线、录音群发、Montauk、走廊两个“好”、彩色头发或雪地循环画面。 |

## 弱效应字段

| 字段 | 记录 |
|---|---|
| `intended_effect` | 较完整 Mary 材料强化同意侵害与 Howard 责任；较长结尾解释 Joel/Clementine 如何在已知缺点后重新靠近。公映压缩则让系统性责任和未来不确定性保持开放。 |
| `observable_design` | 拍摄/发展材料含更长回忆、爱意/罪证与结尾对话；公映版删最明确强迫性背景、缩短走廊说明，并以取档行动、表演停顿和雪地循环承载余义。 |
| `causal_break` | 不是已证明断裂，而是过度决定的弱风险：当新增罪证只把已知施害者变得更“坏”，或长谈只重复已建立的失败条件时，信息可能封闭反读而不改变选择；若它补足同意/选择因果，则不是弱效应。 |
| `likely_audience_detachment` | 在行为已足够的条件下，部分观众可能从 Mary 的选择或情侣的风险承担退到作者解释，伦理与希望变成结论；证据不足时，压缩反而可能让观众因困惑而脱离。 |
| `alternative_causes` | 版本差异还受片长、演员表演、非线性可理解度、未标日期第一稿身份、删场完成度与发行定位影响；不能只归因于“歧义更高级”。 |
| `reception_evidence` | `UNKNOWN`。本地 `DEEP` 没有提供较完整 Mary/走廊版本与公映压缩的受众对照、测试样本或版本化接受研究。总体奖项与长期讨论不能证明这一局部机制。 |
| `smallest_repair` | 先验证观众能否复述必要事实、责任与结尾选择条件。若不能，恢复最小因果信息；若能，再测试额外说明是否改变行动/关系或只收窄解释。允许选择明确版本，不要求制造歧义。 |
| `comparison_limit` | 未标日期第一稿只有 B- 级身份，只能说明发展方向；拍摄稿与成片比较也不能隔离剪辑、表演和发行影响。本卡不能推出“删减必然更深”或“反派必须保持复杂”。 |
