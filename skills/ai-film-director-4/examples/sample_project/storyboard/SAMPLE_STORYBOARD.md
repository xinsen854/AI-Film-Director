# 正式分镜与视频生成Prompt

# SC01｜SH001｜SH001

- EDIT_SHOT_DURATION：11.5秒
- DURATION_BASIS：人物发现信件、停步、确认四周并压住第一反应需要完整可读
- GENERATION_UNIT_ID：GU001

【来源】
- SCENE_ID：SC01
- 对应剧情范围：人物发现桌上的信
- 对应导演节拍：发现与防御

【镜头功能】
- 主要任务：建立发现
- 本镜结束后改变了什么：人物从日常状态进入警觉

【镜头类型】
MS

【基础画面】
- 地点与时间：室内傍晚
- 当前功能区：桌边
- 景别与机位：人物在画面左侧，信在右前景

【摄影参数】
- 摄影机行为：缓慢前移
- 透视倾向或焦段：正常透视
- 摄影机高度：眼平
- 拍摄角度：平视
- 景深与焦点：人物与信依次清晰
- 构图重心：人物和信形成斜线
- 前中后景关系：门框前景、人物中景、桌面后景
- 视线留白与运动留白：人物视线方向留白

【轴线与视线】
- 当前对话轴线或动作轴线：AXIS-1
- 摄影机侧：A
- 人物视线方向：从门口移到信
- 屏幕方向：L2R
- 是否允许越轴：False
- 越轴过渡：无

【资产调用】
--------资产调用完毕-------

【空间与站位】
- 继承的S场景：文字场景身份：普通公寓客厅
- 站位的剧情目的：让发现动作清楚
- 人物之间的可见／可听关系：人物可见桌面、听见室外电梯声
- 人物起始物理位置：门边
- 人物画面位置：画面左侧
- 移动路径：向桌边两步
- 人物结束物理位置：桌前半步
- 是否需要空间占位图：False

【连续画面】
- 进门
- 发现信
- 停步
- 确认四周

【首尾帧锚点】
- 首帧准确画面：人物刚进门，双手空
- 尾帧准确画面：人物停在桌前半步，右手仍垂下
- 首尾之间必须保持不变的连续状态：服装、信件位置和右手状态不变

【关键微反应】
- 接收刺激：看到信
- 第一反应：视线骤停
- 掩饰或重新控制：压低呼吸并看向门口
- 最终动作或回答：重新看向信

【声音】
- 画面内声音：鞋底与地板摩擦
- 环境声远近与空间感：室内底噪和远处电梯
- 特殊声音：无
- 声音桥 / J-cut / L-cut：电梯声延续到下一镜
- 音乐策略：无BGM

【剪辑接口】
- 切入依据：门锁声后
- 切出触发动作或声音：视线落回信件
- 是否动作匹配：True
- 是否视线匹配：True
- 是否由声音提前带入下一镜：False

【连续性锁】
- 服装：深色外套
- 伤势、湿度与污损：无
- 发型与面部状态：略疲惫
- 手持道具及左右手：双手空
- 人物朝向与屏幕方向：面向右
- 人物物理位置：桌前半步
- 光线、时间与天气状态：傍晚室内自然光
- 形态或其他持续状态：警觉
- 本镜人物可依据的已知信息：只知道信件突然出现
- 不得出现的未来信息或未揭露证据：不得显示信件内容
- 特殊能力/技术当前可用范围与代价：现实规则

【下一镜衔接】
- 类型：视线匹配切
- 下一镜从什么状态开始：人物停在桌前半步
- 不得重置：右手、信件位置和警觉状态

----此分镜结束----

# Generation Units｜视频模型执行单元

## GU001｜视频模型最终 Prompt

- 模型：SEEDANCE_2_5｜时长：30秒｜模式：MULTI_SHOT
- Member SH：SH001, SH002
- Packing：30S_BLOCK
- Explicit Cuts：是

【生成目标】
生成一个30秒完整片段，以11.5秒发现镜头和18.5秒选择镜头构成，明确CUT一次

【参考素材职责】
- 无真实媒体引用，仅使用当前文字身份

【初始状态】
人物刚进门，双手空，桌上信件未被触碰

【阶段推进】
### PH01｜完成发现
- 画面与摄影机：中景缓慢前移，人物发现信后停步
- 动作与物理：进门两步后重心停止
- 表演与微反应：视线骤停、压低呼吸、确认四周
- 阶段尾态：人物重新看向信

### PH02｜完成选择
- 画面与摄影机：明确CUT到手与信的近景
- 动作与物理：右手伸出、撤回、再次伸出并撕开封口
- 表演与微反应：电梯声触发撤回，确认安全后动作加快
- 阶段尾态：右手捏住已撕开的信封口

【声音】
室内底噪、电梯声、脚步和撕纸声；无BGM

【保持一致】
服装、信件位置、傍晚光线和AXIS-1连续

【局部限制】
不得提前显示信件内容，不得把30秒窗口理解为每镜30秒

----此生成单元结束----
