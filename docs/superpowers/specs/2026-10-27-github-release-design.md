# AI Film Director Public Release — Design

## Purpose

Publish the user-authorized AFD 4.7.1 Fusion source as a professional, browsable GitHub repository. The public positioning is emotion-driven narrative and cinematic intelligence, not a generic text-to-video generator.

## Goals

- Preserve the original Forge, CineWeaver, AFD, validation, and example files.
- Explain character baseline, event impact, emotional change, behavior, audience experience, and cinematic expression.
- Make evidence-backed distinctions from video-execution projects without comparative superiority claims.
- Provide bilingual orientation, an original cinematic hero, installation, validation, and a usable example.
- Release the authorized source under Apache-2.0.

## Non-goals

- Do not promise direct video or audio generation.
- Do not claim empirical prediction accuracy or experimentally proven audience responses.
- Do not alter story, emotion, directing, or production algorithms.

## Approach

Selected: a restrained obsidian-and-copper research identity, a textless cinematic hero image, concise English and Chinese READMEs, precise Mermaid architecture diagrams, and a self-contained skills-only plugin structure. The alternative—marketing the project primarily as a video production studio—would misrepresent its present execution boundary.

## Constraints

- Repository: `xinsen854/AI-Film-Director`, public, initially empty.
- Core source: user-provided `AI_Film_Director_4.7.1_Fusion (1)(3).zip`.
- Skill path: `skills/ai-film-director-4/`, preserving relative module paths and integrity checks.
- Metadata compatibility fix: remove unsupported `agents/openai.yaml` product restrictions; retain implicit invocation and update its SHA256 manifest entry.
- No secrets, personal data, or proprietary assets introduced.
- GitHub copy must be verified against the local release contents.

## Approval

User selected visual approach A and expressly confirmed public-release rights and Apache-2.0 licensing on 2026-10-27.
