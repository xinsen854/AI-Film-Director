# 与其他开源人工智能影视项目的定位比较

[中文首页](../README.zh-CN.md) · [英文版](COMPARISON.md)

下面的项目并不都在解决同一种问题。本页对比的是各自公开描述的功能侧重，**不是通过统一实验得出的质量排名**。

| 项目 | 公开功能侧重 | 与本项目的关系 |
|---|---|---|
| [CineCrew](https://github.com/Ironieser/CineCrew) | 电影结构描述、多智能体影视流程、参考素材、视觉检查与修复 | 都重视规则和连续性；本项目更强调故事与情绪审计的权威性以及剧本锁定。 |
| [OpenMontage](https://github.com/jedybrilliant/openmontage) | 媒体获取、生成、剪辑、合成及生产看板 | 更偏向实际媒体生产；本项目侧重前期的叙事决策与证据规则。 |
| [StoryMind](https://github.com/LinHao-city/StoryMind) | 分镜规划、视频模型调用与自动合成 | 更接近分镜到视频的执行环节；本项目强调此前的情绪、行为与创作权责。 |
| [Continuity Studio](https://github.com/momorzq-oss/Continuity-Studio) | 本地优先的人物、道具、地点、状态与审核工作台 | 可能形成互补；本项目强调连续性背后的叙事和情绪原因。 |
| [OpenFilm](https://github.com/openfilm/openfilm) | 可编辑的网页场景、时间线、视频素材、字幕与渲染 | 提供动画与视频制作能力，不等同于情绪审计框架。 |

## 值得验证的核心假设

本项目的研究假设是：保留从**人物底色、事件、情绪、选择、表演到观众理解**的因果链，有助于提升导演决策的一致性和可修订性。**这是假设，不是已经证实的结论。**

如果未来进行公平对比，应让各系统使用同一剧本、相同素材、模型约束、预算与时长，再由独立评审检查：

1. 剧情事实和信息揭示顺序是否被保留。
2. 人物情绪变化是否具体、合理、符合剧本证据。
3. 行为与表演是否有情绪原因，而非只贴标签。
4. 真实观众对剧情的理解和情绪反应。
5. 跨镜头人物、空间、道具的连续性。
6. 修改成本，以及实际媒体工具能够完成多少交付。

当前版本尚无上述统一条件下的对照实验数据。

## 已知能力边界

本项目尚不能替代其他系统所接入的视频生成、语音合成、合成剪辑等后端。它的贡献应放在**叙事设计和证据约束层**评估，而不是宣称已经具备独立成片能力。
